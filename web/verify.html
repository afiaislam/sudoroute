Verify a payment certificate

Students create these after a tuition payment arrives, to prove an on-time payment history. The check uses SudoRoute's public Ed25519 key only — no account needed. If a single character was changed, the check fails. Each certificate is also anchored on the Bitcoin blockchain (OpenTimestamps), so you can check it without trusting SudoRoute at all.
